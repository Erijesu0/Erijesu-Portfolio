Frontend Lead — TS Academy Capstone

Solar System Explorer

A data-driven React + Vite web app exploring the solar system, built as the Group 15 capstone for the Phoenix Cohort.

  • Led frontend coordination for the team, architecting a shared component structure (Header, Hero, PlanetGrid, VideoSection, Table, ContactForm, Footer)
  • Coordinated GitHub collaboration — branches, PRs, reviews
  • Fetched and rendered live data via API calls
  • Fully responsive across mobile, tablet & desktop

Challenge — Getting the team aligned on Git collaboration was the first hurdle. We settled on a feature-branch + pull-request flow that kept the main branch clean.

Challenge — The build passed for every teammate but failed on Netlify — a case-sensitivity mismatch between Windows and Linux file systems. Traced it and fixed it with a Git cache reset.
